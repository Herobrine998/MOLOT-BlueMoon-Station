/obj/machinery/atmospherics/pipe/color_adapterPaint decides whether two pipes join, so a network that has to cross a colour boundary on purpose needs somewhere to do it. Repainting a segment grey works and is what the RPD offers, but it leaves nothing on the map to say the boundary was deliberate; this does, and it draws each side in its neighbour's own colour so the join reads at a glance.
