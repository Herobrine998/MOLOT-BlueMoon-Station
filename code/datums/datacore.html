Define Details

#define
MANIFEST_PHOTO_QUEUE_INTERVAL

Пауза между двумя фотографиями манифеста.

Величина выбрана из числа членов экипажа: сотня фотографий на роундстарте раскладывается примерно на три минуты. Меньше - и пик иконочных аллокаций снова попадает в окно массового входа, ради ухода из которого ритм и заведён; больше - и записи персонала слишком долго стоят с плейсхолдером.
